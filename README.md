# 🤖 LLM Chatbot with Memory (DialoGPT)

A conversational AI chatbot built using Hugging Face Transformers.

## Features
- Multi-turn conversation (memory)
- Context-aware responses
- Uses Microsoft DialoGPT

## Tech Stack

- Python
- Hugging Face Transformers
- PyTorch
- DialoGPT

## Example Conversation

You: Hello bro  
Bot: Hey, how's it going?

You: I want to improve my fitness  
Bot: That's great! Staying consistent with workouts and diet helps.

pip install -r requirements.txt
